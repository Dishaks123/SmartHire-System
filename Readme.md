# SmartHire System

## 🚀 Project Overview

SmartHire is a web-based recruitment system designed to simplify and automate the hiring process. It helps recruiters manage candidates, conduct assessments, and streamline interview workflows.

---

## 🛠 Problem Statement

Traditional recruitment processes face several challenges:

* Manual candidate screening
* Time-consuming interview scheduling
* Lack of centralized management
* Inefficient evaluation process

---

## 🌟 Features

* Candidate Registration & Login
* Job Posting and Management
* Resume-based Candidate Matching (Rule-based)
* Multiple Interview Rounds:

  * Aptitude Round
  * Technical Round
  * HR Round
* Dashboard for tracking candidate progress

---

## ⚙️ Tech Stack

Frontend:

* React.js
* Vite
* Tailwind CSS

Backend:

* Node.js
* Express.js

Database:

* MongoDB (can be integrated)

---

## 🧠 How It Works

* Candidates apply for jobs
* System compares candidate skills with job requirements
* A matching score is generated using rule-based logic
* Candidates are shortlisted for interview rounds

---

## 📌 Note

This project was developed by customizing and enhancing an existing recruitment system. Improvements include UI changes, workflow enhancements, and feature modifications.
